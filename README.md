# Ahe Mobile Automation — OAuth branding website

Small, static English-language website for a single-owner Google Drive synchronization workflow using rclone on Android/Termux.

## Site source

- `docs/index.html` — homepage
- `docs/privacy.html` — privacy policy
- `docs/style.css` — visual styling; no JavaScript or analytics

## Publication

GitHub Pages can use `main` → `/docs` after the repository has been intentionally made public (required for GitHub Free). Publication exposes the repository's files and website contents. Never commit OAuth client secrets, refresh tokens, rclone configuration files, synced data, or real device-generated fitness records.

The intended public URLs after publishing on `cathyxub/ahe-mobile-automation` are:

- `https://cathyxub.github.io/ahe-mobile-automation/`
- `https://cathyxub.github.io/ahe-mobile-automation/privacy.html`

These URLs are not live until Pages has been successfully deployed and checked.

### Google OAuth branding test

Use the homepage and privacy-policy URLs on Google Auth Platform → Branding. Whether Google accepts the hosted domain and the app's publishing configuration is **not yet verified**. Do not switch the existing Termux rclone remote before testing this.
