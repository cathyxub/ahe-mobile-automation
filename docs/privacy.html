PRIVACY & DATA HANDLING

Privacy policy

Last updated: 15 October 2026

Ahe Mobile Automation is a personal, non-commercial workflow operated solely by its owner. It uses rclone and Google OAuth to transfer selected files from the owner's device to the owner's Google Drive account. The public website exists to explain this workflow and does not perform the transfers.

1. Information accessed

With the owner's explicit Google authorization, rclone may access Google Drive files permitted by the granted OAuth scope. The intended scope is https://www.googleapis.com/auth/drive.file, which limits access to files the application is authorized to use. Files selected for synchronization may include personal activity or fitness summaries and are treated as private by the owner.

2. How information is used

Authorized Drive access is used only to locate, upload, and update the owner's selected files for personal synchronization. The workflow does not use Google Drive information for advertising, profiling, sale, or training models. No data is made publicly accessible by this website.

3. Storage and sharing

Selected files reside on the owner's device and in the owner's Google Drive, subject to Google's storage and security policies. OAuth credentials and tokens are handled in the owner's local rclone configuration and used to communicate with Google's authorization and API services; they are not collected by this website. There is no developer-operated intermediary server receiving synchronized file contents. The operator does not sell or disclose synchronized data to advertisers or other users.

4. Website data

This is a static informational website hosted on GitHub Pages. It has no forms, user accounts, first-party tracking scripts, or analytics configured by the operator. The hosting provider may process routine technical information under its own policies; see the GitHub privacy statement.

5. Retention and control

The owner decides which files to synchronize, how long to retain them, and when to delete them from the device or Google Drive. The owner can revoke the OAuth grant in their Google Account connections. Revoking access prevents future authorized transfers by this client but does not automatically delete files previously stored in Google Drive.

6. Changes and contact

This policy may be updated if the personal workflow changes. Questions about the project can be directed to the operator through the GitHub profile associated with this website. No private contact address is published here.
